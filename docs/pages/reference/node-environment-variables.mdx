# Node Environment Variables

Every variable consumed by the `openaudio/go-openaudio` binary uses the `OPENAUDIO_*` prefix as the canonical name. Where a legacy (pre-rebrand) name is still recognised as a fallback, it is listed in the **Legacy fallback** column.

:::info
The Go binary picks values in priority order: `OPENAUDIO_*` first, then the legacy name. Cloud-provider credentials (`AWS_*`, `GOOGLE_APPLICATION_CREDENTIALS`, `AZURE_*`) are read directly by the underlying SDKs and are intentionally not prefixed.
:::

## Node identity

| Variable | Default | Legacy fallback | Description |
| --- | --- | --- | --- |
| `OPENAUDIO_NODE_ENDPOINT` | — | `nodeEndpoint` | Public HTTPS endpoint of this node (FQDN, no port). |
| `OPENAUDIO_DELEGATE_PRIVATE_KEY` | — | `delegatePrivateKey` | secp256k1 private key (hex) used to sign validator and storage operations. |
| `OPENAUDIO_DELEGATE_WALLET` | — | `delegateOwnerWallet` | Public wallet address matching the delegate private key. |
| `OPENAUDIO_OWNER_WALLET` | — | `spOwnerWallet` | Wallet that holds the staked $AUDIO bond for this node. |

## State sync

State sync lets a new node bootstrap by downloading a recent snapshot from peers instead of replaying every block from genesis.

| Variable | Default | Legacy fallback | Description |
| --- | --- | --- | --- |
| `OPENAUDIO_STATE_SYNC_ENABLE` | `true` | `stateSyncEnable` | Attempt state sync on first boot (no-op if the DB already has blocks). |
| `OPENAUDIO_STATE_SYNC_SERVE_SNAPSHOTS` | `false` | `stateSyncServeSnapshots` | Periodically produce snapshots and serve them to bootstrapping peers. |
| `OPENAUDIO_STATE_SYNC_KEEP` | `2` | `stateSyncKeep` | Number of snapshots to retain on disk. |
| `OPENAUDIO_STATE_SYNC_BLOCK_INTERVAL` | `100000` | `stateSyncBlockInterval` | Blocks between snapshot creations. |
| `OPENAUDIO_STATE_SYNC_CHUNK_FETCHERS` | `10` | `stateSyncChunkFetchers` | Parallel chunk downloaders during snapshot restore. |
| `OPENAUDIO_STATE_SYNC_RPC_SERVERS` | per-network | `stateSyncRPCServers` | Comma-separated CometBFT RPC servers to fetch snapshots from. |

## Migrating from legacy names

The legacy names listed above are still honoured as fallbacks, so existing deployments keep working without changes. New operators should set the `OPENAUDIO_*` names directly. If you mix the two on the same node, **`OPENAUDIO_*` wins** — make sure they agree on values like `OPENAUDIO_CORE_ROOT_DIR` vs `audius_core_root_dir`, since a mismatch will cause the node to look at the wrong on-disk data directory.
